# Notebooks

Use numbered names so the analysis order is obvious:

- `01_eda.ipynb` — target balance, missingness, distributions, and geographic/temporal patterns
- `02_features.ipynb` — motivated transformations and leakage checks
- `03_models.ipynb` — cross-validation, tuning, comparison, and error analysis
- `04_presentation.ipynb` — concise final narrative and conclusions

Restart the kernel and run all cells before committing. Keep large outputs and reusable functions out of notebooks.
